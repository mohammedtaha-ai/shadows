## Regression details

- IME Enter cannot send; Shift+Enter inserts a newline; Escape closes.
- Artwork alone owns drag/open-main gestures; Ready and Send receive real clicks.
- Close/hide preserve same-scope drafts; retarget discards them before a new
  component can send old text. Pause affects motion only.
- Uncertain Retry reuses the captured body and thread. A runtime identity GET
  refuses a replaced listener before any retry write; its regression failed
  before that guard and passed afterward.
- A first-thread setup marker survives session timeouts, preserving application
  of the configured agent default on retry.
- An admitted old send cannot redirect or replace/clear a newer scope's attempt.
- While a busy/uncertain attempt awaits Retry, its text is read-only so the UI
  cannot imply that a replacement command was admitted.
